Sobre os dados

⌘

Fonte principal

Questlog é a referência prioritária para o catálogo de itens. Os registros são obtidos da listagem pública de armas e mantidos em um arquivo JSON próprio do Companion.

Abrir Questlog ↗
◈

Dados verificados

Nome, categoria, raridade e identificadores são exibidos quando fornecidos pela fonte. Atributos, efeitos e requisitos não serão estimados nem preenchidos por suposição.

⟳

Atualização

O catálogo é atualizado por meio de um arquivo JSON exportado do Questlog e enviado ao repositório. O site lê esse arquivo publicado, sem consultar a API diretamente.
