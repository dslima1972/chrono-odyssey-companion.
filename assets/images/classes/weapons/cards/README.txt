ÍCONES DE ARMAS DOS BOTÕES DE CLASSE

Esta pasta é exclusiva dos ícones exibidos nos cartões/botões de seleção de classe.
Ela é independente de ../weapons/, que contém os ícones utilizados nas páginas
detalhadas de cada classe.

Envie os arquivos PNG com estes nomes:

swordsman-greatsword.png
swordsman-sword-and-shield.png
swordsman-dual-blades.png
ranger-bow.png
ranger-crossbow.png
ranger-rapier.png
berserker-chain-blades.png
berserker-twin-axes.png
berserker-battle-axe.png
paladin-lance.png
paladin-halberd.png
paladin-mace.png
sorcerer-staff.png
sorcerer-manasphere.png
sorcerer-grimoire.png
assassin-sabre.png
assassin-wrist-blades.png
assassin-musket.png

Os nomes devem ser mantidos em letras minúsculas e com apenas uma extensão .png.
Enquanto os novos arquivos não forem enviados, os botões usam temporariamente os
ícones de fallback do Questlog. Isso não altera os ícones das páginas detalhadas.
