# Ícones dos slots de equipamento

Diretório compartilhado para os ícones padrão exibidos nos espaços vazios de equipamento do site.

## Arquivos esperados

Use nomes estáveis, em minúsculas, correspondentes às chaves dos slots:

- `weapon` — arma
- `head` — elmo
- `chest` — peitoral
- `hands` — luvas
- `legs` — calça
- `feet` — botas
- `back` — capa
- `necklace` — colar
- `ring` — anel
- `belt` — cinto

## Convenções

- Preferir PNG com fundo transparente, mantendo o mesmo canvas/proporção entre os ícones.
- Nomear os arquivos como `<slot>.png` (por exemplo, `head.png` e `weapon.png`).
- Manter o desenho centralizado e margens internas consistentes.
- Não incluir fundo, moldura ou texto no arquivo; o tamanho e o tratamento visual serão controlados pelo CSS.
- Este diretório é compartilhado: os ícones podem ser reutilizados no Build Planner e em outras áreas do Compêndio.

A integração visual será feita depois que os arquivos forem enviados e conferidos.
