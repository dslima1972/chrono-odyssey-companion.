# Skill Animations

This folder stores the illustrative GIF animations used by the Skills section of Chrono Odyssey Companion.

## Folder

`assets/images/skills/animations/`

## File naming

Use the Questlog skill ID followed by a lowercase kebab-case skill name:

`<skill-id>-<skill-name>.gif`

Examples:

- `111701-groundbreaker-i.gif`
- `111702-groundbreaker-ii.gif`
- `111703-groundbreaker-iii.gif`

The Questlog skill ID is the primary identifier. It uniquely identifies the skill record, including separate upgrade tiers, and will allow the application to associate each GIF with the correct skill without relying on translated names.

## Upload guidelines

- Upload GIF files directly into this folder.
- Keep the original Questlog skill ID in the filename.
- Use the `.gif` extension.
- Prefer optimized files; target approximately 1 MB or less when practical.
- Use transparent backgrounds when available.
- Do not upload reference images, spritesheets, prompt files or preview videos here.
- These animations are illustrative visualizations, not official in-game animations.

## Current status

GIFs are collected here first. They are not automatically displayed in the application; integration into the Skills interface will be handled separately after the animations have been reviewed and approved.
